H4G CTF Challenge Analysis Workbench
====================================

The Docker build contains the integrated forensic/reverse-engineering toolchain
and the Hack4Gov-style challenge-pack extensions.

MAIN MODULES
------------
http://127.0.0.1:8000/
    Module home.

http://127.0.0.1:8000/workbench
    Artifact Workbench: files, PCAPs, WAV/audio, images, PDF, email, archives,
    binaries, steganography, USB HID/keylogger captures, recursive extraction,
    flag detection, decoder lab, and evidence timeline.

http://127.0.0.1:8000/web-lab
    Authorized Web Lab: scoped GET/POST/HEAD/OPTIONS requests, headers, body,
    response time, flags, and redirect-chain inspection. localhost and RFC1918
    private IP ranges are allowed automatically. Public hosts must be explicitly
    added to the authorized scope in the Web Lab before requests are sent.


RUN WITH DOCKER DESKTOP
-----------------------

1. Start Docker Desktop.

2. Open PowerShell:

cd "C:\Users\user\OneDrive\Desktop\STUFFS\ctf-challenge-analysis-toolkit"

3. Use the integrated-workbench branch while testing the pull request:

git checkout feature/integrated-workbench
git pull origin feature/integrated-workbench

4. Rebuild because the Docker image contains the analysis tools:

docker compose down
docker compose build --no-cache

5. Start:

docker compose up

6. Open:

http://127.0.0.1:8000

To stop, press Ctrl+C or run:

docker compose down


ANALYSIS TOOLCHAIN
------------------

file, strings, xxd, exiftool, binwalk, foremost, tshark, radare2, rabin2,
readelf, objdump, nm, zsteg, steghide, upx, ffmpeg, ffprobe, sox, pdfinfo,
pdftotext, pdfimages, and bsdtar.

The workbench also contains Python analysis modules for Base64/Base32/hex/URL
and XOR decoding, whitespace steganography, GPS coordinate distance analysis,
email header extraction, damaged-header/signature scans, and USB HID decoding.


CHALLENGE WORKFLOW
------------------

For a file/PCAP/audio/document challenge:

1. Open Artifact Workbench.
2. Upload the original challenge artifact.
3. Allow Upload + Analyze to triage it.
4. Use Analyze Entire Challenge to process recovered child artifacts.
5. Inspect Tool Output, Preview / Hex, Decoder Lab, artifact graph, and flag
   candidates without leaving the app.

For a web challenge:

1. Open Authorized Web Lab.
2. Private CTF IPs such as 172.16.x.x are already within local/private scope.
3. For a public CTF host, explicitly add the hostname to Authorized Scope.
4. Enter the URL and inspect responses/redirects. The Web Lab does not provide
   automatic exploitation, credential stuffing, or brute-force attacks.


WORKSPACE RECOVERY
------------------

The workspace database persists through Docker restarts. At startup, the app
repairs valid moved artifact paths and removes stale database trees whose files
no longer exist. Re-uploading a stale artifact rebuilds its backing file and
analysis tree automatically.
